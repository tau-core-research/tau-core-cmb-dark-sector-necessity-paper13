# Tau Core CMB Dark-Sector Necessity Paper 13

Private scaffold for Paper 13:

**CMB constraint mapping for dark-sector necessity in Tau Core**

This repository starts a narrow CMB-facing protocol for deciding what a Tau Core
cosmology must reproduce before any dark-sector necessity claim can be made.

## Main Claim

The paper defines a reproducible constraint map from CMB observables to Tau Core
requirements. It distinguishes three claim levels:

```text
TC0: no effective dark-sector response required
TC1: effective Tau base-field response required
TC2: standard CDM/Lambda-like benchmark still required
```

The first version does not fit CMB spectra. It identifies which CMB features
make a completely no-dark Tau Core cosmology difficult to defend, and which
features a Tau base-field response layer would have to reproduce.

Current interpretation rule:

```text
B_tau^base
M_seed / delta M_root
-> M_tau = F_tau(M_seed, B_tau^base, constraints)
-> D_tau[M_tau; B_tau^base]
-> CMB projection/readout scaffold
-> possible dark-sector-like residual.
```

Here `M_seed` is the endpoint-blind initial morphology/constraint state,
`B_tau^base` is the base-field/support medium whose properties help determine
which morphology can stabilize, `D_tau[M_tau; B_tau^base]` is only a candidate
Tau base-substrate response target, and the CMB-facing quantity would be a
readout footprint if later source, channel, dimension, gauge/null, and
cross-role gates pass. This is not a physical source claim or a dark-sector
verdict.

Current acoustic diagnostic-route update:

```text
Planck PR3 TT/TE/EE source vector
-> deterministic O_CMB^peak extraction
-> acoustic diagnostic pre-score policy
-> endpoint-blind Tau prediction-vector spec Y_tau^ac
-> no physical score until Y_tau^ac is populated.
```

This is a route update only. It does not claim a Tau CMB fit, Planck
likelihood, Tau response validation, or dark-sector verdict.

Current acoustic population decision:

```text
Y_tau^ac prediction-vector spec declared
Y_tau^ac prediction values not supplied
diagnostic acoustic score not run
status: Y_TAU_AC_POPULATION_EXPLICIT_FAIL
next: tau_cmb_acoustic_operator_population_work_order_v01
```

This is an explicit Tau-side population failure, not a physical CMB failure and
not a dark-sector decision.

## Does Not Claim

- It does not claim that Tau Core has explained the CMB.
- It does not claim that dark matter does not exist.
- It does not claim a physical Tau dark-sector field has been detected.
- It does not claim a Boltzmann solver, perturbation solver, or CMB likelihood.
- It does not claim Planck, ACT, SPT, BAO, lensing, or supernova validation.
- It does not claim a final dark-sector verdict.

To verify or obtain the official local working copies listed in the source
receipt, run:

```bash
python scripts/acquire_cmb_source_data.py
```

This checks Planck PR3 and ACT DR6 lensing local files under `data/external/`,

status artifacts under `data/derived/`.

To extract the compact ACT DR6 lensing observable payload from an acquired
local ACT DR6 lensing package, run:

```bash
python scripts/build_cmb_act_dr6_lensing_observable_payload.py
```

This writes the 18-row ACT lensing convergence bandpower payload, a
source-audit table, and a summary. It is an observed-data payload only: it is
not a Tau prediction, likelihood run, score, or dark-sector verdict.

To lock the observed-side reduced-score adapter for that payload, run:

```bash
python scripts/build_cmb_act_dr6_lensing_observed_score_adapter.py
```

This writes the 18-bin observed vector adapter, inverse covariance, and
formula summary for
`chi2_tau=(y_obs-y_tau)^T C_obs^{-1} (y_obs-y_tau)`. The score remains closed
until a Tau-side prediction vector in the same 18-bin basis is supplied.

To generate the exact Tau-side 18-bin prediction template and score preflight,
run:

```bash
python scripts/build_cmb_act_dr6_lensing_tau_prediction_score_preflight.py
```

The expected score-ready input path is
`data/score_ready_input/act_dr6_lensing_tau_prediction_vector_v01.csv`. The
repository currently includes that file as a Tau Core-specific null-response
control vector: all 18 Tau prediction values are `0.0`, with
`tau_core_null_response_control_v01` as the source id. The preflight therefore
computes a null-control reduced score, not a physical Tau response score:
`chi2_tau=2129.1187283145146`, `chi2_per_naive_dof=118.28437379525081`.

To screen a predeclared family of nonzero Tau Core-style morphology response
controls against the same observed adapter, run:

```bash
python scripts/build_cmb_act_dr6_lensing_tau_shape_response_controls.py
```

This is diagnostic shape screening only. In the current artifact, the best
predeclared nonzero control reduces the null-control chi-square from
`2129.1187283145146` to `401.4430238676094`, but it remains a control rather
than a physical Tau response or dark-sector verdict.

To materialize the best screened nonzero control as a candidate packet for
Tau-side derivation or rejection, run:

```bash
python scripts/build_cmb_act_dr6_lensing_tau_nonzero_response_candidate_packet.py
```

This writes a separate 18-row candidate vector and four open derivation

To transfer the ACT-selected nonzero candidate unchanged to the Planck lensing

```bash
python scripts/build_cmb_planck_lensing_cross_readout_holdout_for_tau_candidate.py
```

This uses the Planck 9-bin lensing bandpowers and the bottom-right 9x9 Planck

while the unchanged ACT-selected nonzero candidate gives
`307.71562329316146`, a fractional chi-square improvement of
`0.8441884684689893`. This partially addresses the independent-readout
obligation, but it is still a reduced diagnostic, not a physical Tau response,
not a Planck likelihood, and not a dark-sector verdict.

To audit the nonzero candidate derivation obligations after the ACT+Planck
diagnostic results, run:

```bash
python scripts/build_cmb_tau_lensing_nonzero_candidate_derivation_status_audit.py
```

This writes a formula-level status audit. It closes the zero-source known limit
only for the diagnostic response family `R_tau^kk(L)=A*S(L)`, because `A=0`
gives a zero prediction in every lensing bin. It marks the Planck transfer as a
partial cross-readout fulfillment. The two remaining blockers are now explicit:
derive or reject the shape parameters `L_c,p,q` from Tau-side morphology, and
derive or bound the amplitude `A` from Tau-side normalization without endpoint
selection.

To split the nonzero candidate into explicit Tau-origin routes, run:

```bash
python scripts/build_cmb_tau_lensing_response_origin_route_audit.py
```

This declares four origin routes: the rejected-as-best null control, seed-only
projection, seed-induced Tau base-field response, and a higher-burden hybrid
route. No route is selected. The artifact records the exact remaining target:
derive or reject `L_c=120`, `p=0.5`, `q=1.0`, and `A=1e-7` from one of those
Tau-side routes without endpoint fitting.

targets, run:

```bash
python scripts/build_cmb_tau_lensing_base_field_route_prederivation_packet.py
```

This selects `ROUTE_02_BASE_FIELD` only as the next work route, not as the true

`M_seed + B_tau -> M_tau=F_tau(M_seed,B_tau,constraints) -> Phi_tau_eff=D_tau[M_tau;B_tau] -> Pi_lens[Phi_tau_eff] -> R_tau^kk`
and records five open acceptance tests for deriving or rejecting `D_tau`,
`Pi_lens`, the shape parameters, and amplitude without endpoint selection.

To materialize the minimal base-field operator ansatz and audit its
formula-level properties, run:

```bash
python scripts/build_cmb_tau_lensing_base_field_operator_ansatz_packet.py
```

This records the ansatz
`Phi_tau_eff=D_tau[M_tau;B_tau]`, `R_tau^kk(L)=A*K_lens(L)`, with
`K_lens=x^p/(1+x^(p+q))/max`, `x=L/L_c`. It verifies only mathematical
compatibility: dimensionless shape, normalization, low-L activation, high-L
suppression, and zero-response limit. It still leaves `D_tau`, `Pi_lens`, the
shape-parameter origin, and amplitude origin open.

To factor the operator ansatz into smaller Tau-side derivation targets, run:

```bash
python scripts/build_cmb_tau_lensing_factorized_response_derivation_attempt.py
```

This decomposes the diagnostic kernel into `x=L/L_c`, seed activation `x^p`,
base-field screening `1/(1+x^(p+q))`, readout normalization, and amplitude
slots. The factorization exactly reconstructs the current ansatz at formula
level, but none of the factors is promoted to a Tau-side derivation.

To conditionally close the two central shape factors as a minimal seed plus
base-field response model, run:

```bash
python scripts/build_cmb_tau_lensing_seed_screening_minimal_closure_attempt.py
```

This records the conditional assumptions under which an initial morphological
seed condition, together with Tau base-field properties, can produce a
seed-conditioned activation `x^0.5` and base-field screening

unconditional Tau derivation: `L_c=120`, `A=1e-7`, and the exponents still need
endpoint-blind Tau-side origin or a clearly labeled conditional-scoring
boundary.

The same artifact records the inverse-constraint reading: morphology plus 4D
readout behavior can constrain compatible `B_tau` response-family candidates
only when null/gauge, wrong-family, and holdout controls are declared. It does
not identify the Tau base field or select a unique physical response equation.
